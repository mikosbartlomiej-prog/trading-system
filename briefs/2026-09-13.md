```

```
`'.1f if rsi else 'N/A''` is not a valid Python format spec — it throws inside `check_long_signal()` /
`check_short_signal()`, is swallowed by the surrounding `except Exception`, and the function returns
`None` regardless of whether the breakout/volume/RSI conditions were actually met. Net effect:
**momentum-long (and all 12 leveraged ETFs, which share the same code path) has never been able to emit
a live BUY signal since this line was introduced on 2026-05-05.** Reproduced again in Friday's last real
session tick (2026-09-11 19:56 UTC, live job log, run `34641481474`): `USO` scored **+0.516** (above the
0.35 entry threshold) and `AMD` scored **+0.390**, both threw `Invalid format specifier` instead of
producing a signal; all 12 leveraged tickers threw the same error. First flagged unaddressed since
2026-08-28 — **16 consecutive days**. One-line fix: `RSI={(f'{rsi:.1f}' if rsi else 'N/A')}` at both
lines 239 and 313.

**Net effect: even with a plan queued every night and real breakout candidates scoring above threshold
most days, nothing can execute — #1 blocks the allocator path, #2 blocks the price-monitor direct-alert
